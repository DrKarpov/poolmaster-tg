# Changelog

## v1.1.0 — 2026-11-09

- Private price message widget with six timeframes, exact MEXC OHLCV, USDT volume, MA7, candle selection and separate history/scale gestures.
- Read-only candle reserve loading, coalesced rendering and deferred data application during gestures; history browsing preserves the accepted market quote.
- Weekly farming widget with four pool series, tap-to-toggle values, current equal-weight mean, complete TVL and source-backed refresh.
- Client-only gold coin menu, 50/50 outcome, reflection, varying speed, whole-coin bounce and optional toss/landing haptics.
- Independent per-user/message queues and configurable active concurrency; shared bounded market caches remain.
- Fixes for Back visibility, Desktop decimal-comma numeric/geometry corruption, incomplete daily collection retries and settings rollback after persistence failure.
- Public TST vector compatibility replaces private farming/coin marks. Optional private-logo handling remains for legacy PNGs; public tests no longer require internal concept/audit documents.
- Updated architecture, guides, configuration, testing, provenance and blurred portfolio images. Group commands/text inline results remain; daily/3D farming and group inline widgets are not enabled.
