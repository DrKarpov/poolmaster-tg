# Security policy

The supported public source snapshot is `v1.1.0`.

Never post bot tokens, API credentials, private keys, user data, or administrator IDs in public issues or discussions. Do not include sensitive data in a security report. Production credentials, persistent state, deployment files, and private operational records are intentionally excluded from this repository.

If GitHub Private Vulnerability Reporting is enabled, use it for security findings. Otherwise, contact the repository owner through the GitHub profile. If a credential is exposed, revoke or rotate it immediately and report only the affected filename or location, not the value.

Widget actions are checked against owner, message, revision and session closure. Copied messages do not receive private interactive ownership. Price/farming SQLite sessions, JSON preferences and destination records are private runtime data. The coin outcome/animation is client-side and does not control funds. Public CI uses synthetic credentials and mocked transports, never production state.
